Virtual construct is a Virtual Machine environment which consists of entirely raw control over the machine.
Every register is available for full control. There are no rings. Only priviledges in a process.

What is there in VC?

Custom Virtual CPU architecture

Custom Virtual GPU architecture

Custom Virtual Filesystem

Custom Virtual Firmware (You can also make your own firmware!)

And different execution methods for edge cases. Including the IE.1 (Import Export, dot signals version) Which allows VC programs to interact with the host's machine and filesystem.
